# Notice and Credits

## Subject matter

This project is an independent, condensed aid for applying the clean-code principles and
craftsmanship practices popularized by Robert C. Martin, as described in *Clean Code: A Handbook
of Agile Software Craftsmanship* (Prentice Hall, 2008).

- It restates named frameworks and terminology (for example the Boy Scout Rule, SRP, F.I.R.S.T.,
  and the smell and heuristic codes C, E, F, G, J, N, and T) in original, condensed wording.
- It does **not** reproduce the book's text, code listings, examples, figures, or chapter
  structure, and it is organized by topic rather than by the book's table of contents.
- The frameworks, terminology, and heuristics remain the intellectual property of Robert C.
  Martin and his publisher. This project is not affiliated with or endorsed by them.
- It is a practical aid, not a substitute for the book. Read the book for the full treatment.
